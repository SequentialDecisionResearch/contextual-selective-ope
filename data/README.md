# Data

This project uses three experimental layers.

## Synthetic data

Generated directly by the experiment scripts.

## Semi-Synthetic data

The experiments use public datasets including:

- Digits
- Wine
- Breast Cancer

These datasets are loaded through scikit-learn.

## Open Bandit Dataset

The Open Bandit Dataset is not redistributed in this repository.

The OBD experiments use the public Random and Bernoulli Thompson
Sampling production logs. Please obtain the dataset through the
official Open Bandit Pipeline resources before running the OBD scripts.
