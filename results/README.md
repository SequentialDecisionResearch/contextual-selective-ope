# Results directory and version caution

`paper_snapshot/` contains a small set of **final summary CSVs** copied from the author's `tables(1).zip` archival export. Source protocol metadata is in `../experiment_protocol/`.

The root `results/` CSVs were already present in the public GitHub snapshot. Some are **older exploratory/OBD DR audit artifacts** rather than the final `PRE-PAPER-FINAL-R6-DRFIX` results. In particular `final_numeric_summary.csv`, `obd_dr_code_audit.csv`, `obd_dr_empirical_audit.csv` MUST NOT be cited as the manuscript's final OBD performance. They are kept to avoid silently deleting historical work. Final OBD numbers should be drawn from the versioned output and final tables.

Not all long-form raw estimates, original OBD logs, or checkpoints are included. This package does not independently reproduce the full paper.
