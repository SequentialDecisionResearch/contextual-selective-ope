# Contextual Off-Policy Evaluation for Selective Safe Policy Improvement

Reproducibility materials for the research project:

**Contextual Off-Policy Evaluation for Selective Safe Policy Improvement:  
From Global Policy Value to Calibrated Local Deployment Decisions**

## Overview

Standard off-policy evaluation usually asks whether a candidate policy is better on average.

This project asks a more practical question:

> **Where is the historical evidence strong enough to justify replacing the baseline policy?**

A candidate can improve global policy value while still being harmful in some pre-defined groups. The framework therefore combines:

- local candidate-vs-baseline OPE;
- cross-fitted doubly robust estimation;
- bootstrap-based uncertainty;
- effective-sample-size and overlap diagnostics;
- one-sided lower confidence bounds;
- selective local deployment.

The deployment rule is

\[
d_g = \mathbf{1}\{L_g(\alpha) > \delta\},
\]

where \(L_g(\alpha)\) is a lower confidence bound for local improvement. If the evidence is not strong enough, the baseline is retained.

## Experiments

The study uses three complementary layers:

1. **Synthetic experiments**  
   Exact counterfactual truth for studying calibration, overlap, model misspecification, and harmful deployment.

2. **Semi-Synthetic experiments**  
   Digits, Wine, and Breast Cancer datasets with real feature geometry and known finite-population policy truth.

3. **Open Bandit Dataset (OBD)**  
   Real production logs from Random and Bernoulli Thompson Sampling policies, with an independent policy log used as an external reference.

## Main Result

Across the completed Synthetic experiments:

| Policy | Harmful Exposure | Candidate Coverage |
|---|---:|---:|
| Global rollout | 30.15% | 100% |
| Local Gate | 0.0056% | 69.80% |

In the primary Semi-Synthetic local-stress experiments, harmful exposure falls from **10.17%** under global rollout to **0.0269%** under the local Gate, while retaining **82.64%** deployment coverage.

The main conclusion is:

> **Average improvement is not a deployment license.**

Scope

This work studies selective deployment in a one-step contextual-bandit setting. The safety statement is local and marginal for pre-defined groups; it is not a universal safe-RL or sequential-policy guarantee.
