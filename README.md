# From Global Off-Policy Evaluation to Local Deployment

**Subtitle:** Calibration-Aware Selective Policy Improvement  
**Author:** Shenggang Li (Independent Researcher)  
**Status:** Pre-publication research package; author review is ongoing.

This repository accompanies the 28-page manuscript *From Global Off-Policy Evaluation to Local Deployment: Calibration-Aware Selective Policy Improvement*. It studies **context-specific, evidence-aware deployment** of a fixed candidate policy relative to a baseline in contextual bandits.

The rule is \(d_g=\mathbf{1}\{L_g(\alpha)>\delta\}\) for **predefined** groups. A statistically favorable global estimate alone does not justify deploying the candidate in all groups. Conditional confidence-bound guarantees are **not unconditional real-world safety guarantees**.

## Three experimental layers

| Layer | Data | Role |
|---|---|---|
| Synthetic | Controlled, truth-known contexts | Calibration and harm/coverage stress tests |
| Semi-Synthetic | scikit-learn Digits/Wine/Breast Cancer | Real feature geometry with known finite-population policy values |
| OBD | Random and Bernoulli Thompson Sampling logs | External, independent on-policy comparison; not per-group counterfactual oracle truth |

From the manuscript's historical formal runs:

| Layer | Global harmful exposure | Selective harmful exposure | Selective coverage |
|---|---:|---:|---:|
| Synthetic | 30.15% | 0.0056% | 69.80% |
| Semi-Synthetic local stress | 10.17% | 0.0269% | 82.64% |

These are **archived results**, not claims that the latest clean runner reproduces them byte-for-byte. See [docs/REPRODUCIBILITY.md](docs/REPRODUCIBILITY.md) for the version boundary.

- `results/paper_snapshot/`: selected, compact derived tables matching the manuscript version.

## Quick code check (not a full experiment)

Install in an isolated Python environment:

```bash
python -m pip install -r requirements.txt
python code/validate_installation.py
```

`obp` is needed for real OBD loading, not for the mock self-test. `BCSPI_RUN_MODE` defaults to `smoke` in this distribution so accidentally starting a full week-long experiment is less likely.

Do **not** run `code/run_all.py` in `paper` mode expecting an exact regeneration of the published CSVs; the current clean runner settings are different from the archived formal-run manifests.

## Paper, data and scope

The Open Bandit Dataset is **not redistributed**: obtain it through the official Open Bandit Pipeline resources. Synthetic data are generated by code; Semi-Synthetic datasets are provided by scikit-learn.

This study is one-step contextual-bandit evaluation, **not** sequential MDP policy improvement. Its theoretical false-admission bound assumes a valid one-sided lower confidence bound. Empirical coverage falls below nominal levels under some weak-overlap conditions.
